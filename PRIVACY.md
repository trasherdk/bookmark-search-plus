# Privacy

Bookmark Search Plus runs entirely in your browser.

- It reads and updates **your bookmarks** on this device.
- It stores UI preferences (open folders, filters, text size) and the **last import backup** in `chrome.storage.local`.
- Import can also save a backup file that **you** choose (or download). That file stays on your computer.
- It does not create accounts, collect analytics, or send bookmarks — or anything else — to a server.
- Favicons are the ones the browser has already cached.

Nothing leaves the browser unless you export or copy it yourself.
